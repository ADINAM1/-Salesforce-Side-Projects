# Salesforce Side Projects

Each folder is a self-contained Salesforce DX project with its own `sfdx-project.json`. Run CLI commands from inside the project folder, and open that folder (not the repo root) in VS Code.

| Project | What it is |
| --- | --- |
| [`enrollment-portfolio`](enrollment-portfolio/) | Program Waitlist Manager + Agentforce Enrollment Assistant: capacity, automatic waitlisting and time-limited seat offers for a childcare nonprofit, with a live LWC and an Agentforce agent built on the same Apex service layer. |
